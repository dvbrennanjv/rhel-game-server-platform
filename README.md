# rhel-game-server-platform
A harden RHEL game server platform fitted for Minecraft.

---

## Technologies Used
- Virtual Box: Local Hypervisor for gamehost, backup and monitoring Virtual Machines
- RHEL 9 Linux: Chosen OS for Virtual Machines
- GitHub: Version Control
